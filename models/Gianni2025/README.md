The folder contains the world builder files for idealized Philippine Sea Plate slab and plate geometries in a 3-D box. These GWB models were created by Zonglin Guo (U. Miami) for the subduction models contained within Gianni et al., 2025 (doi...). There are three model geometries:

1) single-slab.wb: A single subduction zone test model (i.e., only including the Japan-Izu-Bonin-Marianas subduction zones, and not the Ryukyu-Nankai subduction zone
            on the other side of the Philippine Sea Plate).

2) double-slab.wb: Equivalent to the single slab model (#1), but with the addition of the other, Ryukyu-Nankai subduction zone.

3) double-slab_extended-weak-zone.wb: Equivalent to the main double slab model (#2), but with an alternate weak zone geometry for the boundary between
            the Philippine Sea Plate and the adjacent Eurasian Plate.

Model geometries #1 and #2 are used for all numerical models in the main text of Gianni et al. (2025). 
Model geometry #3 is used for a supplemental test (to verify our main results are independent of weak zone geometry)
